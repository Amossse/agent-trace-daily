## 中文

开源了 Agent 执行轨迹日报 Skill。它从选定的本地日志汇总昨日任务、项目变更、文件访问和产出候选，保留可观察事件序列，并明确报告缺口。安装后告知 Agent 创建默认每天上午 11:00 的定时任务，时间可改。支持 Codex、Claude Code 与通用 JSONL，MIT 许可。默认只输出结构信息，真实日志和日报不上传。

https://github.com/Amossse/agent-trace-daily

## English

Agent Trace Daily is an open-source Skill for yesterday's recorded Agent tasks, tool calls, project/file activity and output candidates. It preserves the selected normalized timeline and reports coverage gaps. Installation hands the Agent a native daily scheduling request, default 11:00 with configurable time/timezone. Codex, Claude Code and generic JSONL inputs; MIT licensed, structural privacy default, no automatic uploads.

https://github.com/Amossse/agent-trace-daily
